# Reapertura: contrato nativo de autenticación

Estado: **experimental, no resuelto**. Se realizaron intentos reales limitados con la cuenta de laboratorio; no se obtuvo sesión ni se descargó una partida en esta reapertura. No se demuestra una prohibición del proveedor ni que sea imposible. Se detuvieron los intentos tras dos respuestas iguales para evitar reintentos indiscriminados. El cliente propuesto debe considerarse una hipótesis, especialmente su esquema de respuesta y su comparación de identidad.

## Herramienta

`backend/.venv/bin/python experiments/phase6-6/native_login.py` solicita correo y contraseña interactivamente, sin eco para contraseña. El cuerpo y la interpretación de respuesta son **hipótesis no verificadas**. No reintenta, no sigue redirecciones, limita el tamaño, no imprime respuestas ni persiste secretos. Si una respuesta futura satisface sus comprobaciones conservadoras, solicita los identificadores de instalación sin eco y llama a `ModernCloudSaveProvider` en memoria. El éxito de descarga demostraría que el servicio aceptó el Bearer para una copia estructuralmente válida; haría falta evidencia adicional para afirmar que el contenido corresponde al titular. No captura desafíos; se detiene ante una respuesta desconocida. No usa una sesión importada.

Las pruebas de esta reapertura no establecieron que el campo `credential` deba ser nulo, qué cabeceras hacen falta, ni si el gateway recibió y aceptó el esquema correcto. El error 502 no prueba una restricción de autorización. El laboratorio tiene credenciales e instalación disponibles; no se necesita pedir al usuario esos secretos. El requisito concreto para avanzar es observar el contrato completo de una solicitud legítima del cliente y la respuesta de éxito o recibir el contrato y autorización de integración del proveedor. La ausencia de documentación pública por sí sola no basta para concluir que el proveedor lo impide.

Las contraseñas, los tokens, los identificadores y los cuerpos privados no se incorporaron al repositorio. Ninguna petición en esta reapertura modificó o subió una partida. El valor de 10.000 gemas comunicado por el propietario sirve como referencia, sujeto a cambios posteriores; no se ha vuelto a comprobar aquí.
