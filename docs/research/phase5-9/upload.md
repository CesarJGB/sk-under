# Subida

La etapa de subida estaba condicionada a una descarga independiente íntegra y verificable. Esa condición no se cumplió. No se identificó el contrato de escritura, no se construyó ni transmitió una petición y no se alteró la cuenta de laboratorio desde Linux. Las rutas y firmas presentes en metadata no bastan para inferir autorización, estructura ni validaciones. Las escrituras remotas siguen deshabilitadas. La subida oficial de 5.8 es evidencia de la interfaz oficial, no de un cliente Linux.
