# Conservación y aceptación

En 5.8 el cliente oficial subió y recuperó su propia copia; el resumen mostró 1.000 gemas tras reiniciar y `game.data` cambió de 0 a 1.000. El JSON privado extraído de memoria posteriormente tiene 1.000 gemas y es estructuralmente procesable. Esto no demuestra que ese JSON sea la respuesta de red exacta ni establece la procedencia de cada campo.

Para una eventual subida desde Linux los tres niveles permanecen **sin demostrar**: aceptación de solicitud por el servidor, conservación y devolución del contenido, y recuperación y uso por el cliente oficial. Ninguno se probó en esta fase. No se modificaron gemas ni se transmitió una copia.
