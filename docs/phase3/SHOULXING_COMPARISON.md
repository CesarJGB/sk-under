# Comparación con SHOULXING

Se revisó el commit `685691e09798aa6d39ae2f44f29e31ad6423b98d`, distribuido bajo Apache-2.0. `shoulxing.py` delega en `soking`. El flujo sustantivo está en extensiones CPython 3.11 compiladas para Android AArch64. Se consultaron símbolos, cadenas y referencias estáticas de la investigación local de ese commit. Las extensiones y sus rutinas de instalación quedaron sin ejecutar en el VPS. [Código de SHOULXING](https://github.com/STE4LPH/SHOULXING/tree/685691e09798aa6d39ae2f44f29e31ad6423b98d)

| Aspecto | SHOULXING | Muestras atribuidas a 8.6.0 |
| --- | --- | --- |
| Lectura local | Abre preferencias privadas de Android, extrae un identificador de selección y construye rutas para los archivos de objetos, temporada y estadísticas. | La API recibe bytes de una copia y selecciona el tipo por su objeto JSON. No requiere preferencias, root ni acceso a la instalación. |
| Versiones | Las rutas y el nombre del módulo `soul5` aportan contexto histórico. Las rutinas revisadas no establecen una verificación general de versión. | Dos marcadores internos tienen valores observados. El resto se reconoce por esquema. |
| Transformación | `__modencrypt` realiza lectura binaria, Base64, DES-CBC y retirada del relleno. Las rutinas de objetos y armas consumen JSON. | Se confirma la misma composición. La clave estadística se valida independientemente de la general. |
| Estructuras | Los objetos incluyen una colección `itemUnlock`, recursos y planos. Hay rutas históricas para estadísticas y preferencias de personajes y gemas. La rutina de moneda de temporada revisada termina sin aplicar cambios. | Se leen nueve estructuras, incluidas las variantes de objetos, estadísticas y temporada. Las preferencias XML y las recetas históricas de edición quedan fuera de la cobertura. |
| Escritura | Las rutas revisadas serializan, rellenan, cifran y codifican Base64. Algunas escriben directamente usando `r+`, `seek`, `write` y `truncate`, y otras abren con `w`. | El adaptador prepara una descarga de los bytes recibidos con nombre propio. El motor exige igualdad exacta y reabre la salida. |
| Integridad | Relleno y análisis JSON figuran en la ruta de lectura. En el código revisado no se estableció un MAC ni una verificación de aceptación en el juego. | Se añade validación estructural y comparación de bytes. La autenticidad y la aceptación por el cliente siguen sin verificar. |

Para contrastar los parámetros del cifrado se consultaron los literales de dos llamadas a DES y del IV en un segundo proyecto histórico, con un ensayo independiente sobre las nueve copias. También se consultó SKDEditor como antecedente del método. El adaptador es una implementación propia de la estructura observada. Este repositorio no incorpora código, binarios ni catálogos de las referencias. Los valores de cifrado se configuran localmente.
